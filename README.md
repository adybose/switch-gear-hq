# Switch Gear HQ

A T-shirt store run by AI agents in Slack via [Switch](https://docs.switchagents.ai/).
One founder; Claude Code and Codex agents run engineering, fulfilment, finance, marketing
and support. Built for the WeMakeDevs "Flip the Switch" hackathon.

> Demo store. No real payments, printing or deliveries; partners and payments are simulated.

Work in progress. See `docs/plan.md` for the org and build plan and `docs/tasks.md` for progress.
