# #engineering

Tasks, bugs, PRs, reviews, deploys and incidents.

- **Agents:** `@builder`, `@builder-codex`, `@reviewer`
- **Links:** → #approvals (merges and deploys), → #research (questions)

## How this room works

- `@builder` (and `@builder-codex` when the founder names a task) works one task per branch and PR from `docs/tasks.md`. `@reviewer` reviews every PR; author and reviewer are always different agents.
- Only the founder merges to `main`. Nobody deploys without the founder.
- Other rooms report bugs here with the record ID and steps to reproduce. Builder reproduces, writes a failing test, then asks the founder for a task ID before fixing.
- Update messages are short; no Markdown tables.
